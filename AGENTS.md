# AGENTS.md

Guidance for AI coding agents (Claude, Codex, Cursor, etc.) working in this repository.

## What this is

A small TypeScript library (`src/`) published to npm as `viziot-mqtt-client-nodejs`. It wraps
the [`mqtt`](https://www.npmjs.com/package/mqtt) package with a Promise-based API tailored to
the VizIoT.com IoT platform's topic structure and authentication scheme.

## Layout

- `src/client.ts` — the `VizIoTMQTT` class (all behavior lives here).
- `src/errors.ts` — the `VizIoTError` type thrown for validation failures.
- `src/index.ts` — public exports.
- `test/` — Vitest unit tests; the `mqtt` module is mocked, no real broker is used.
- `examples/` — runnable CommonJS and TypeScript usage examples kept in sync with the README.
- `dist/` — build output (gitignored, generated by `npm run build`, never edited by hand).

## Commands

- `npm run build` — bundle with tsup (CJS + ESM + `.d.ts`).
- `npm test` — run the Vitest suite.
- `npm run lint` / `npm run format` — ESLint / Prettier.
- `npm run typecheck` — `tsc --noEmit`.

## Conventions

- Public API is Promise-based; do not reintroduce callback-style methods.
- Keep error messages in English; throw `VizIoTError` for input validation, let transport
  errors from `mqtt` propagate unchanged.
- Any change to the public API must be reflected in `README.md` and `CHANGELOG.md` (see
  `CONTRIBUTING.md` for the versioning/release process).
- Do not hand-edit `dist/` — it's regenerated by the build.
